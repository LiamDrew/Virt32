This file contains the register outputs corresponding to the test file 
segmentIDTest.um

The test works by loading a power of 2 into r1 in the range [2^0, 2^16]. Next,
a segment of that size is requested from the um, with the ID being stored in
in r2. Only the progression of r1, r2 is stored in this document as all other
registers are zeroed in this test (and have been manually confirmed to exhibit
that expected behavior).
